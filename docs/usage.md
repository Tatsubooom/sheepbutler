# 使い方

## 通知の種類

| 通知 | いつ | 内容 |
|---|---|---|
| 🔴 即時通知 | 対応が要るメールが届いたとき | 見出し / 差出人と締切 / Gmail へのリンク。選考の段階が変わったときは「確定」「取り消す」のボタン付き |
| ⏰ 締切リマインド | 締切の 72 時間前と 24 時間前 | 締切の一覧 |
| 🐑 まとめ報告 | 毎日 7:00 と 21:00 | 今日（夜は明日）の予定、近い締切、選考状況、確認してほしいメール |

### 振り分けのルール

メールごとに LLM が「締切・重要度・興味度・種類・対応が要るか」を抜き出し、点数（0〜1）をコードで計算する。

- **即時**: 点数が 0.7 以上で、返信・提出・申込などの対応が要るもの。選考の個別連絡（日程調整・結果・書類の依頼など）は点数に関係なく即時
- **まとめ報告**: 点数が 0.4 以上のもの。受付完了やアンケートなど、選考が動かない連絡もここ
- **記録のみ**: それ以外。通知はせず、件数だけをまとめ報告に載せる

即時にしないもの:

- ナビサイトの広告やスカウトの一斉送信（点数が 0.5 以上ならまとめ報告に載せる）
- 志望企業として登録していない会社の説明会・イベントの案内
- 夜間（0:00〜7:00）と、1 時間に 5 通・1 日に 20 通を超えた分（まとめ報告に回す）

詐欺の疑いがあるメールには ⚠️ を付けてまとめ報告に載せる。

## Discord のコマンド

| コマンド | 内容 |
|---|---|
| `/status` | 選考中の企業と、次にやること |
| `/deadlines` | 7 日以内の締切 |
| `/today` | 今日の予定と、確認してほしいメール |
| `/pause [hours]` | 通知を止める（既定 24 時間）。止めている間の通知は再開後のまとめ報告に回る |
| `/resume` | 止めた通知を再開する |
| `/ask <質問や依頼>` | 執事に自由に聞く・頼む |

### /ask の例

- 「今どこまで進んでる？」「A社の次の締切はいつ？」「先週届いた面接のメールは？」
- 「B社は辞退した」「C社の二次面接に進んだ」 → 選考状況の変更案
- 「D社の志望度を A にして」 → 志望度の変更案（次に届くメールの判定から使われる）
- 「まとめ報告は朝 6 時半と夜 10 時にして」「即時通知は 1 日 10 通まで」 → 設定の変更案

変更の依頼には「反映する」「やめる」のボタンが付き、**ボタンを押すまで何も変わらない**。変更案は 24 時間で期限が切れる。
チャットから変えられる設定は、まとめ報告の時刻・夜間の時間帯・即時通知の上限・リマインドの時刻・しきい値・重み・LLM の 1 日の費用上限・連絡なしと見なす日数だけ。志望企業の一覧や LLM のモデルは `config.yaml` で変える。

## 振り分けを調整する

多すぎる・少なすぎると感じたら、過去のメールで確かめてから値を変える。

```bash
gcloud auth application-default login   # 初回だけ
go run ./cmd/review -days 7             # 直近 7 日の判定結果（段階・点数・理由）
# config.yaml を編集してから
go run ./cmd/review -days 7 -rescore    # 新しい値で計算し直した結果（LLM は呼ばないので費用はかからない）
```

よく変える値（`config.yaml` の `triage`）:

| 値 | 効果 |
|---|---|
| `thresholds.digest` | 上げるとまとめ報告に載るメールが減る |
| `thresholds.bulk_digest` | 上げると広告・一斉送信がまとめ報告に載りにくくなる |
| `thresholds.urgent` | 上げると即時通知が減る |
| `weights` | 締切・重要度・興味度のどれを重く見るか |
| `exclude` | 差出人・件名のキーワード・転送元ごとに、LLM に送らず記録のみにする |
| `jobhunt.companies` | 志望企業。`none` にした企業のメールは記録のみ |

決まったら `upload-secrets.sh` と `deploy.sh` で反映する。しきい値と重みは `/ask` からも変えられる（再デプロイ不要）。

## 止める・再開する

| したいこと | 方法 |
|---|---|
| 通知だけ一時的に止める | `/pause`、再開は `/resume` |
| 予算の 50% で止まったのを再開する | `./scripts/deploy.sh` |
| 予算の 100% で課金が外れたのを再開する | 請求先アカウントを再リンクしてから `./scripts/deploy.sh` |
| 完全にやめる | Google Cloud のプロジェクトを削除し、専用 Gmail の転送設定と OAuth の権限を取り消す |
