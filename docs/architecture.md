# 仕組み

## 全体の流れ

```
各メールアドレス ──転送──▶ 専用 Gmail ──watch──▶ Pub/Sub(gmail-push)
                                                        │ push
                                                        ▼
Cloud Scheduler ──15分おき──▶ sheepbutler（本体・非公開） ◀──push── Pub/Sub(chat-jobs)
                                 │  取り込み → 判定（Claude） → 選考状況の更新 → 通知        ▲
                                 ▼                                                        │
                             Firestore ◀──────────── sheepbutler-chat（公開） ──────────────┘
                                 ▲                         ▲
                                 │                         │ コマンド・ボタン（署名付き）
Discord / LINE ◀──通知──────────┘                       Discord

Cloud Billing の予算 ──Pub/Sub──▶ sheepbutler-guard ──超えそうなら──▶ 本体を停止
```

1. **取り込み**: Gmail の新着通知を受け、前回の続きから差分を取得して Firestore に保存する。保存するのは差出人・宛先・件名・冒頭の抜粋・受信日時だけで、90 日で自動削除する
2. **判定**: 件名と本文の冒頭（既定 1500 字）を Claude に送り、要約・種類・締切・重要度・興味度・対応の要否・選考の動きを抜き出させる。段階（即時・まとめ・記録のみ）は抜き出した値からコードで計算する（設定で調整でき、理由も説明できるように）
3. **選考状況**: 選考の連絡から企業ごとの段階を更新する。後戻りする変化や自信の低い変化は「要確認」にして、ボタンで確定・取り消しできるようにする
4. **通知**: 即時通知はすぐに、締切リマインドとまとめ報告は 15 分おきのジョブで送る。送った記録を残し、二重に送らない
5. **チャット**: 公開サービスは Discord の署名を確かめてから応答する。重い処理（`/ask`）は Pub/Sub で非公開の本体に渡し、本体が回答で Discord の表示を書き換える

## 安全のための設計

| 心配 | 対策 |
|---|---|
| メールの読み書き | Google の権限は `gmail.readonly` と `calendar.readonly` だけ。送信・削除・変更はできない |
| 本体を外部から呼ばれる | 本体と予算の監視は Cloud Run の IAM で非公開。Pub/Sub と Scheduler の専用サービスアカウントだけが呼べる |
| 公開しているチャットを悪用される | すべての要求で Discord の Ed25519 署名を確認し、Bot の持ち主以外の操作は拒否する。チャットのサービスアカウントは Firestore と、質問を渡すトピックへの発行だけを許可 |
| メールの文面で LLM が操られる（プロンプトインジェクション） | 判定の LLM は値を抜き出すだけで、段階はコードが決める。`/ask` の LLM に渡すメールの情報は「第三者の文章」と明示し、LLM ができるのは参照と変更案の作成だけ。実際の変更は利用者がボタンを押したときに、値を検証してから行う |
| メール由来の文字列で Discord のメンションが飛ぶ | 送信時にメンションを無効にする |
| 費用が膨らむ | Google Cloud は予算の 50% で本体を停止、100% で課金を外す。Claude API は 1 日の上限を超えたら呼ばない。Cloud Run は最大 1 インスタンス |
| 秘密情報の漏えい | API キーやトークンは Secret Manager に置き、Git にはコミットしない。各サービスは必要な秘密情報だけを読める |

## データ（Firestore）

| コレクション | 内容 | 削除 |
|---|---|---|
| `messages` | メールの要点、判定結果、通知の状態 | 受信から 90 日（`RETENTION_DAYS`） |
| `companies` | 企業ごとの選考の段階と履歴、チャットで設定した志望度 | 手動 |
| `proposals` | `/ask` で作った変更案 | 期限（24 時間）後に自動 |
| `notifications`、`audit` | 送った通知と、判定の記録 | 自動 |
| `usage` | LLM の 1 日ごとの費用 | 手動（1 日 1 件で小さい） |
| `state` | Gmail の処理位置、一時停止、チャットで変えた設定 | — |
